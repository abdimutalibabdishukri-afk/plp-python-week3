# Week 3 Assignment on Conditions and Loops

## Grade Reporter & Bug Hunt

This repository contains my Week 3 Python assignment on conditions and loops.

### Files

* `grade_reporter.py` - Uses a for loop and if/elif/else statements to calculate grades, pass/fail counts, and the average score.
* `bug_hunt.py` - Contains the corrected while-loop program with three BUG comments explaining the errors and fixes.
* `screenshots/` - Contains screenshots showing both programs running successfully.

### Bug Hunt Reflection

The hardest bug to find was the loop condition because it did not produce an error message. The program could run but stop before adding the number 5. I knew something was wrong because the program was supposed to calculate 15, but the result was lower than 15.
